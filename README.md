# Программа Интерпретатор Зов Для Арифметики (ПИЗДА)

*Если Вам не нравится название языка, то сосите неженки ;)*

Проект по большей части вдохновлён, но не основан на Учебном Алгоритмическом Языке Андрея Петровича Ершова. Рекомендую воспринимать данный проект всерьёз, т.к. он не готовился как шутка к Первому Апреля. Не смотря на свою серьезность, это менее полноценный язык, на котором нельзя даже что-то писать

Имейте ввиду, что т.к. у меня не было много времени, проект разрабатывался второпях, и содержит много багов и не законченых частей. Также заранее НЕ извиняюсь за отсутствие какой-либо нормальной документации. Если у меня будет время, я её добавлю в каком-нибудь виде. Наслаждайтесь!

## Быстрый Старт

Вам не потребуется установить компилятор(планирую тупо запихнуть сюда токенайзер и остальные шняги ведь парсер это скучно)

### Компиляция в Исполняемый Файл

На данный момент поддерживается только платформа Windows x86-64(не сейчас но заранее пишу)

Для других платформ можно попробовать НИЧЕГО
